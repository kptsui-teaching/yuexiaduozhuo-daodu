# 《月下獨酌》範文導讀

漢華中學中國語文科｜中四至中六自學／課堂投影頁

## 檔案

| 檔案 | 用途 |
|------|------|
| `index.html` | 單檔教學網頁（導讀、全文、語譯、字詞、章法／寫作手法、自測 45 題、影片） |
| `Code.gs` | Google Apps Script：接收學生交卷，寫入試算表 |
| `README.md` | 本說明 |
| `ks4_16b_text.pdf` | 教育局原文參考（已附） |

## 快速開始（學生端／預覽）

1. 用瀏覽器直接開啟 `index.html`（本機預覽路徑見老師備註）。
2. 填寫**班別、學號、姓名**。
3. 依序完成「內容理解／字詞解釋／寫作手法」三節自測（各 15 題）。
4. 全部完成後按「交卷至老師試算表」。

> 目前 `GAS_WEBAPP_URL` 留空作預覽：成績仍會顯示，並以本機 `localStorage` 暫存草稿；未能上傳試算表。

## 老師設定：交卷試算表

1. 新建或指定一張 Google 試算表。
2. **擴充功能 → Apps Script**，刪去預設內容，貼上 `Code.gs` 全部程式碼。
3. （可選）若腳本**未**綁定該試算表，在 `Code.gs` 填寫：
   ```js
   var SPREADSHEET_ID = '你的試算表ID';
   ```
4. 在編輯器選取函式 `setup` → **執行**一次（授權試算表存取）。會建立分頁「**交卷紀錄**」與表頭。
5. **部署 → 新增部署 → 網頁應用程式**：
   - 說明：可填「月下獨酌導讀交卷」
   - 執行身分：**我**
   - 具有存取權的使用者：**任何人**
6. 授權並複製「網頁應用程式」網址。
7. 開啟 `index.html`，在腳本最上方把網址貼入：
   ```js
   const GAS_WEBAPP_URL = "https://script.google.com/macros/s/……/exec";
   ```
8. 用瀏覽器開啟該網址（GET）應見到 `{"ok":true,...}`，即健康檢查通過。

### 交卷紀錄欄位

時間、班別、學號、姓名、內容理解得分、字詞解釋得分、寫作手法得分、總分、滿分、百分比、備註（錯題摘要）

## 老師設定：影片

在 `index.html` 腳本頂部：

```js
const YOUTUBE_ID = "rFjApOxt7gw";  // 寶寶老師陪你快速溫範文｜《月下獨酌》
```

已預填上述 ID（VPA 確認）。若要更換，只改 ID（非完整網址）。留空則顯示佔位框。

## 題庫

自測三節為**校本自測**（內容理解／字詞解釋／寫作手法各 15 題，合共 45 題；含構思精奇、擬人、悲喜轉折、層遞構圖）。選項顯示時會洗牌；來源陣列第一個選項為正確答案。

## 全文來源

文言原文依教育局「指定文言經典學習材料」參考版本（`ks4_16b_text.pdf`），未改字。  
來源：https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/recommended-passages/ks4_16b_text.pdf

## 注意

- 無需外掛 JS 框架；字體優先系統 CJK／Noto Sans TC。
- 交卷以 `fetch` + `text/plain` 送 JSON，配合 Apps Script `doPost`，避免 CORS 預檢問題。
- 請勿把含學生姓名的試算表公開分享給「網路上的任何人」編輯；網頁應用程式「任何人」僅指可呼叫交卷介面。
