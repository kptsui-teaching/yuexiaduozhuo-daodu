《月下獨酌》範文導讀

一、導讀

對象：中四至中六　｜　篇章：《月下獨酌》（其一）　｜　作者：李白（唐）　｜　用途：學生自學＋課堂投影

背景

李白於唐朝天寶年間奉詔入長安，出任翰林供奉。他原以為可以一展抱負，其後卻因受權貴排擠而漸為玄宗疏遠，於是狂歌痛飲，藉以排解胸中鬱悶。《月下獨酌》組詩（共四首）就是在這樣的背景下寫成；本篇為其一。詩中圍繞題目的「獨」字着筆，卻忽發奇想——舉杯邀明月、對影成三人，寫盡孤獨中的自我排遣，亦流露對酒與月的鍾愛。

作者簡介

作者李白（公元 701–762），字太白，號青蓮居士。祖籍隴西成紀（今甘肅省秦安一帶），先世遷徙西域，後隨父遷居蜀地。年青時辭親遠遊，漫遊各地，求仙學道，嗜酒任俠。才氣橫溢，擅長各體詩歌，作品豐富，《月下獨酌》《將進酒》《靜夜思》等尤為傳誦，後世譽為「詩仙」。

記住三個關鍵

① 獨・三人

處境
花間一壺酒，獨酌無相親——無人相伴。
奇想
舉杯邀明月，對影成三人（己・月・影）。

白話：開頭就說：花叢間放着一壺酒，我一個人喝，身邊沒有可親近的人。接着忽然奇想——舉起酒杯邀請天上的明月，再面對自己的身影，於是「我、月、影」變成了「三個人」。題目明明是「獨酌」，詩裡卻幻出三人，這正是構思最精奇之處；三人越熱鬧，反而越襯出真正的孤獨。

② 悲喜轉折

復獨
月不解飲，影徒隨身 → 仍覺孤單。
暫歡
暫伴月將影，歌徘徊、舞零亂；醒同歡，醉分散。

白話：月畢竟不會喝酒，影子也只是空跟着身體動，情感一下子又掉回孤獨。可是詩人說：那就暫時讓月亮和影子陪着我，趁着春天及時行樂吧！於是我唱歌，月亮好像也來回徘徊；我起舞，影子便散亂跳動。清醒時大家一起歡樂，喝醉以後卻又各自散開——歡喜裡仍藏着孤單。整首詩悲喜交替，一步步都扣着「獨」字。

③ 無情・雲漢

忘情
永結無情遊——泯除物我之別的忘情之交。
相期
相約於邈遠銀河（雲漢），自我紓解。

白話：醉後雖然分散，詩人卻把筆鋒一轉：我要與月光、身影永遠結下「無情」之遊——這裡的「無情」不是冷酷，而是忘掉世俗得失、物我界限的忘情境界。大家相約到遙遠的銀河上再續這段交遊。孤獨沒有困住他，反而見出豁達與高情遠致：能自我排遣，不為現實所困。

溫習口訣

花間一壺獨無親，舉杯邀月影三人；月不解飲影徒隨，暫伴將影樂及春；我歌徘徊舞零亂，醒時交歡醉分散；永結無情期雲漢，詩仙太白要記清。

二、全文

李白《月下獨酌》（其一）　｜　文本依教育局「指定文言經典學習材料」參考版本

月下獨酌 (其一)
李白

起・獨酌

花間一壺酒，獨酌無相親。

舉杯邀明月，對影成三人。

承・復獨

月既不解飲，影徒隨我身。

暫伴月將影，行樂須及春。

轉・歌舞

我歌月徘徊，我舞影零亂。

醒時同交歡，醉後各分散。

合・永結

永結無情遊，相期邈雲漢。

三、語譯

以下語譯供自學參考，考試請以課文原文為準。

起・獨酌

花叢之間放着一壺酒，我獨自酌飲，沒有可相親近的人。

舉起酒杯邀請明月，面對自己的身影，便成了三個人。

承・復獨

月亮既不懂得飲酒，影子也只是徒然跟隨着我的身體。

且暫時讓月亮和身影相伴，行樂須趁着春天（美好時光）。

轉・歌舞

我唱歌，月亮彷彿來回徘徊；我起舞，身影便散亂搖動。

清醒的時候一同歡樂，醉了以後便各自離散。

合・永結

願永遠結下這忘情的交遊，相約在遙遠的銀河之上。

四、重點字詞

以下重點詞語宜連同課文語境記誦。（注釋參考教育局材料）

相親互相親愛、親近。此處指可相親近的人。「獨酌無相親」——獨自飲酒而沒有可相親近的人。
三人指李白、明月和李白的影子。「舉杯邀明月，對影成三人」。語意出自陶潛《雜詩》：「欲言無予和，揮杯勸孤影。」
徒徒然、空。「影徒隨我身」——影子只是空自跟隨我的身體。
將和、共。「暫伴月將影」——暫時與月亮和身影為伴。
及春趁着春天。及：趁着。「行樂須及春」——行樂須趁着春天。
徘徊往返迴旋、來回走動。「我歌月徘徊」——我唱歌，月亮彷彿來回徘徊。
交歡一同歡樂。「醒時同交歡」——清醒時與月、身影一起歡樂。
無情即忘情，語出《莊子·德充符》，指泯除是非得失、物我之別的境界。「永結無情遊」——與月光和身影（本為無情之物）永遠結伴交遊。
相期相約。「相期邈雲漢」——（與月和身影）相約於遙遠的銀河之上。
邈遙遠。○粵音「寞」[mok6]。「相期邈雲漢」。
雲漢銀漢，即銀河。「相期邈雲漢」——相約在遙遠的銀河。

五、章法／寫作手法

1. 五言古詩・圍繞「獨」字

本篇為五言古詩（組詩四首之其一）。內容可分五部分：起寫獨酌無親；次寫邀月對影成三人；再寫月不解飲、影徒隨身而復歸孤獨；繼寫暫伴月影、歌舞交歡而又醉後分散；終以永結無情遊、相期雲漢收束。全篇悲喜轉折，皆扣題目「獨」字，卻終不為「獨」所囿。

2. 主要寫作手法

  • 構思精奇：題本「獨酌」，詩偏幻出三人；月影伴說，反覆推勘，愈形其獨。（孫洙《唐詩三百首》評）
  • 擬人：自「對影成三人」後，多將月、影人格化——月徘徊、影零亂、同交歡、各分散。
  • 悲喜轉折：悲己之獨 → 喜成三人 → 悲月不解飲 → 喜歌舞暫歡 → 悲醉後分散 → 喜永結雲漢，層層推進。
  • 層遞構圖：花間獨飲圖 → 舉杯邀月、對影邀飲圖 → 歌徘徊、舞零亂之三人同樂圖，情景交融。
  • 淺近而錘鍊：語言近乎口語，「純乎天籟」；又煉「暫」（暫得之樂更可貴）、「無情」（呼應不解飲、徒隨身，無情中見有情）等字。

3. 情志

既抒內心孤獨，亦寫對酒與月的鍾愛；篇末相期雲漢，見自我紓解、不為現實所困的高情遠致。

4. 結構示意

花間獨酌・無相親 → 邀月對影・成三人 → 不解飲・徒隨身 → 暫伴・及春行樂 → 歌徘徊・舞零亂 → 醒交歡・醉分散 → 永結無情・相期雲漢。
